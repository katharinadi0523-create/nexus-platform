1 定位与出发点

Claw 的定位，放在与 AF 平台的对比里看最清楚：

维度AF 平台（平台端）Claw 个人工作台（使用端）
服务对象开发者、企业管理员个人用户
核心任务构建、调试、发布能力使用能力完成具体工作
组织单位项目个人
能力来源在项目中构建平台发布的能力；v2.0.1 起增加个人资源
上手方式按需配置，有专业门槛开箱即用，少配置
沉淀内容项目资产个人上下文：资料、对话产物

定位：Claw 是面向个人、开箱即用的 AI 工作台。它以平台发布的能力为基础，以工作空间为上下文沉淀的核心。

从这个定位出发，本期有三个出发点。后面的每个问题、每处改动都对应其中一个。

出发点 A

与 AF 平台低耦合

Claw 与平台之间以“已发布的能力”为接口，不依赖项目上下文。无论从哪个入口进入，用户看到的能力和数据都保持一致。

本期体现为能力以已发布资源为准；数据不再挂在项目上。
出发点 B

面向个人，开箱即用

以个人用户的使用习惯为准：减少前置配置，默认即可使用；信息架构和交互对齐主流的个人 AI 工作台。

本期体现为能力集中管理，模型在对话中选择；导航按使用频率分层；右侧区域用于查看文件。
出发点 C

上下文沉淀的核心空间

个人工作台是用户上下文沉淀的核心空间。上传的资料、对话的产物持续积累在工作空间里，并能在后续对话中复用。

本期体现为工作空间进入一级导航，与对话双向打通。

3 产品规划与迭代节奏

分两个版本推进。v2.0.0 把形态、定位和逻辑捋顺；v2.0.1 在此基础上补齐个人资源，并开始按语义组织工作空间。

本期 · v2.0.0

产品层重构：捋顺形态、定位和逻辑

  1. 能力库去项目化，合为一个页面
  2. 模型在对话中选择
  3. 工作空间进入一级导航，与对话打通
  4. 导航按使用频率分层
  5. 右侧区域改为摘要栏 + 查看器
下一步 · v2.0.1

个人资源与语义化工作空间

  1. 个人资源：在使用端直接增加自己的资源，比如注册 MCP、导入技能。资源归个人所有，不经过发布和审核。
  2. 工作空间按语义组织：文件按语义归类，具体做法待定。

v2.0.0 本期改动

改动一句话解决的问题出发点
4.1 能力库去项目化，只放已发布的技能、插件、工作流和智能体；合为一个页面，用“我的 / 发现”切换1、3AB
4.2 模型去掉设置里的主模型、参数和备用模型，在输入框里选4B
4.3 工作空间不再挂在项目上；进入侧栏第一位，与对话打通2、7AC
4.4 导航侧栏只放常用对象，低频配置收进头像下的设置5B
4.5 右侧区域摘要栏列出本次对话的文件，查看器用来打开文件6B

本期不做

  • 不改 AF 平台的项目逻辑和项目存储卷，平台上的智能体照旧使用项目卷。
  • 不接入项目内未发布的资源，也不直接接入知识类资源。
  • 个人资源（注册 MCP、导入技能）放到 v2.0.1。
  • 不做用户之间的共享，不迁移原来按智能体分开的老数据。

v2.0.1 · 个人资源：缩短从“有资源”到“能用上”的链路

现在用户想用一个自己的 MCP 或技能，要先到平台注册或导入，再发布、审核、上架广场，最后回到使用端添加。v2.0.1 允许在使用端直接注册、导入，进来的就是个人资源。

第二部分展开：五处改动怎么做

4 改动详解

以下逐条展开，作为详细设计的起点。各节末尾的“待确认”汇总在第 5 节。

4.1 能力库：去项目化，合成一个页面

问题回顾。同一个个人智能体的配置一直保留，但“这次能选什么”由进入时的项目决定（问题 1）。

只放已发布的资源。Claw 里不再出现项目，也不再能选项目里没发布的资源。不管从哪个项目进来，能选的范围都一样。

资源Claw 里能不能选说明
技能能 只限已发布来自技能广场
插件（MCP、OpenAPI）能 只限已发布来自插件广场
工作流能 只限已发布对比稿的方案一里有；放在插件里还是单独一类，待确认
智能体能 只限已发布召唤已发布的项目 Claw 来干活，产物写回个人工作空间（4.3）
知识库、数据库、本体检索不能直接选它们没有发布逻辑。先在 AF 平台配给一个智能体并调试好，发布后在 Claw 里召唤这个智能体
项目里没发布的资源不能选不做项目选择器
  • 好处：入口不再改变能力范围；发布本身就是一道质量关口，以后加审核也有地方放；知识、本体这类专业资源在 AF 平台配置和调试，配置和调试在同一个地方。
  • 代价：想用知识库或本体检索，要绕一步，先找到一个配好了这些能力、已经发布的智能体。

合成一个“能力”页面，用“我的 / 发现”切换。参照 Claude 的 Customize（Skills / Connectors / Plugins，加上 Yours / Discover）、WorkBuddy 的“专家 · 技能 · 连接器”加“已安装”、Codex 的 Plugins / Skills。侧栏只有一个“能力”入口。页面顶部按类型切换：技能、插件、智能体；旁边是“我的 / 发现”。

视图放什么能做什么
我的已经添加的，系统内置的置顶并标“系统”启用或停用、移除；内置的只能停用
发现广场里已发布的，按分类浏览，可以搜索“＋”添加；已添加的显示“已添加”

待确认：工作流放在插件里还是单独一类；插件里的“本体动作”还要不要；已添加的资源在广场下架后，是标“不可用”还是自动移除。

4.2 模型：去掉主备，在输入框里选

  • 设置里不再有模型页。主模型、模型参数和备用模型列表都去掉。
  • 输入框里加模型下拉。按对话记住所选模型；新对话默认用上次选的那个（建议）。
  • 选的模型不可用时，在对话里直接提示，让用户换一个，不在后台悄悄切到备用模型（建议）。

待确认：模型参数（温度等）在个人工作台里是否完全不露出。

4.3 工作空间：提到左导第一位，打通对话和文件

归属。一个人只有一个个人 Claw，用这个人的个人存储卷，这就是工作空间。从 AF 平台的哪个项目进来都是它，在 Base 里切换项目卷也不影响它。项目 Claw 继续用项目存储卷，一个项目可以有多个，规则不变。

存储卷归属谁在用
个人存储卷个人，一人一个个人 Claw；在个人 Claw 里召唤的已发布智能体，这次对话的产物也写在这里
项目存储卷项目，一个项目可以有多个项目 Claw 自己的 Agent.md、记忆和项目文件，不搬进个人工作空间

位置。“工作空间”是侧栏第一个入口。一期只有两个系统文件夹：“对话产出”（按对话自动建子文件夹）和“我的上传”。文件来自哪个智能体，用来源列和筛选区分，不再按智能体分目录。

和对话的交互。

操作入口效果
上传输入框 ＋ › 上传文件；拖文件进输入框存进“我的上传”，出现在摘要栏 › 资料
引用已有文件右侧工作空间页签 › 引用到对话；从文件树拖进输入框输入框里出现文件标签，智能体优先处理这些文件。首页不单独放“从工作空间引用”
智能体产出自动写到 对话产出 / <对话名>，标“新”，出现在摘要栏 › 产物；记录是哪个智能体在哪个对话里生成的
下载、重命名、删除悬停图标、⋯ 菜单删除要二次确认，只由用户来做，智能体不能删

4.4 导航：什么显示，什么收起

R1
侧栏只放“内容会越积越多、干活时会回来打开”的东西工作空间、自动化、能力，加上对话列表。
R2
调一次就很少再动的，全部收进设置设置只有一个入口：左下角头像。头像菜单里不再放任何内容页。
R3
每类东西只有一个家技能、插件、智能体的家在能力页，文件的家在工作空间。其他地方只能引用或做快捷操作，不另开管理页。
现有入口现在位置新位置
智能体、技能、插件侧栏三个一级入口，各带两层 tab合进“能力”一个页面（4.1）
知识侧栏一级移除。通过已发布的智能体使用（4.1）
文件管理头像下拉侧栏第一位 · 工作空间（4.3）
自动化侧栏一级不变
Claw 配置 · 模型头像下拉去掉，在输入框里选（4.2）
Claw 配置 · Agent.md头像下拉设置 › 设定（个人 Claw 的设定，和“关于我”放在一起）
接入渠道、我的账号头像下拉设置 › 渠道、设置 › 账号
存储配置弹窗文件页内设置 › 存储，只读显示个人存储卷和容量

左下角：头像菜单和设置

左下角只放头像和名字。点开是一个小菜单，里面只有身份信息、“设置”和“退出登录”；所有低频配置都在设置弹窗里，头像菜单不再放任何内容页。

位置内容来自现在的哪里
头像菜单 · 顶部头像、姓名、账号角色（个人 Claw 使用者）我的账号页

待确认：头像菜单里要不要放“返回 AF 平台”；账号页要不要显示所属组织（现在的账号页只有账号和账号角色）。

4.5 右侧区域：摘要栏 + 查看器

右侧只有一块区域，有两种宽度。摘要模式约 260px，是这次对话的文件索引；打开工作空间或任意文件后切到查看模式，约占屏幕 45%，可以拖宽。开关在对话标题栏右侧，宽屏（1440px 以上）默认展开，并记住用户上次的选择。

摘要栏分组显示什么交互
产物 (n)本次对话新增或修改的文件，最新的在上面，最多 5 条，标“新增 / 已修改”点文件在查看器里预览；“查看全部”打开工作空间页签并定位到 对话产出 / <对话名>
资料 (n)本次上传的文件和从工作空间引用的文件，标“上传”或“引用”点文件预览；悬停可以下载，或“在工作空间中定位”
  • 没有内容的块不显示。两块都空时，只显示一句：“这次对话上传、引用或生成的文件会出现在这里。”
  • 不进摘要栏的：工作空间本身（左侧导航打开）、进度（停在输入框上方）、智能体（标题栏）、工具调用（对话流）。
  • 查看器的页签：第一个固定是“摘要”，点它回到摘要模式；然后是“工作空间”（完整文件树，和左侧工作空间是同一份数据）；之后是打开的文件预览，支持表格、文档、PDF、Markdown、图片和 HTML。其他页签都关掉后回到摘要模式。
  • HTML 可以全屏看。HTML 文件在查看器里按网页渲染；工具栏右侧有“全屏”按钮，点开后铺满整个窗口，按 Esc 或点“退出全屏”回到对话（图 12）。

5 交给详设：每处改动要回答的问题

改动详设要补的待确认
4.1 能力库技能、插件、智能体三类的列表和卡片字段；“我的”和“发现”的空状态；添加、停用、移除的交互工作流放在插件里还是单独一类；插件里的本体动作还要不要；广场下架后标“不可用”还是自动移除
